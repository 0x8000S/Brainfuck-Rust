# brf

用 Rust 编写的 Brainfuck 方言解释器。在保留标准 8 指令的基础上，增加了数字字面量、位运算、栈操作、可定制循环条件，以及**函数定义与调用**。

> 从 "Hello World" 到 "'add(>+<)add!"，只需一行。

## 特性

- **标准 Brainfuck**：完整支持 `><+-.,[]`
- **嵌套循环**：递归下降解析，任意层级 `[]` 嵌套
- **自动扩容内存带**：向右无限延伸，向左边界保护
- **字节回绕**：`u8` 范围自动溢出/下溢
- **REPL 交互模式**：逐行执行，内存带与函数表状态保持
- **文件执行模式**：直接运行 `.bf` 或 `.brf` 脚本
- **EOF 安全处理**：输入结束时 `,` 指令写入 0
- **函数系统**：支持定义、调用、嵌套调用与多字符函数名
- **零外部依赖**：纯标准库实现

## 安装

```bash
git clone https://github.com/0x8000S/Brainfuck-Rust.git
cd Brainfuck-Rust
cargo build --release
```

编译完成后，可执行文件位于 `target/release/brf`。

## 使用

### 文件模式

```bash
brf hello.brf
```

### REPL 模式

```bash
brf
>>> ++++++++[>++++[>++>+++>+++>+<<<<-]>+>+>->>+[<]<-]>>.>---.+++++++..+++.>>.<-.<.+++.------.--------.>>+.>++.
Hello World!
>>> exit
```

REPL 模式下，**内存带状态与函数表在多次输入之间保持**，方便分步调试与增量编程。

## 指令集

### 标准指令

| 指令 | 说明 |
|------|------|
| `>` | 指针右移 |
| `<` | 指针左移 |
| `+` | 当前格加 1 |
| `-` | 当前格减 1 |
| `.` | 输出当前格 ASCII 字符 |
| `,` | 从输入读取一个字符到当前格 |
| `[` | 循环开始 |
| `]` | 循环结束 |

### 扩展指令

| 指令 | 说明 | 示例 |
|------|------|------|
| `0` ~ `9` | 向当前格写入对应数字 | `9` 等价于 `+++++++++` |
| `=` | 将当前格清零 | `=` 等价于 `[-]` |
| `~` | 按位取反 | `~`（0 → 255） |
| `{` | 左移一位（`value *= 2`） | `1{{{` = 8 |
| `}` | 右移一位（`value /= 2`） | `8}` = 4 |
| `!` | 输出当前格的**数值**（而非 ASCII） | `!` 输出 `65` |
| `:` | 将当前格压入栈 | 保存临时值 |
| `;` | 从栈弹出到当前格 | 恢复临时值 |

### 循环增强

标准 BF 的 `[]` 以"当前格非零"为循环条件。brf 允许在 `[` 后紧跟一个数字，指定**终止条件**：

```brainfuck
[5>+]      ; 当前格不等于 5 时，执行 >+
[3>+]      ; 当前格不等于 3 时，执行 >+
```

### 函数系统

brf 支持通过 `'` 定义函数，通过函数名调用。

**定义函数**：
```brainfuck
'name(body)
```
- `'` 开始函数定义
- `name` 为函数名（支持多字符，如 `add`、`loop_left`）
- `(` 开始函数体
- `)` 结束函数体

**调用函数**：
```brainfuck
name        ; 直接写函数名即可调用
```

**示例**：
```brainfuck
'inc(+)            ; 定义 inc 为 "当前格加 1"
'dec(-)            ; 定义 dec 为 "当前格减 1"
'add_two(inc inc)  ; 函数体可调用其他已定义函数

5 add_two !        ; 当前格 = 5，调用 add_two → 7，输出 7
```

**嵌套调用**：
```brainfuck
'b(--)
'a(+++b)           ; a 的函数体里调用 b
5 a !              ; 5 + 3 - 2 = 6，输出 6
```

函数表在 REPL 模式下**持久保持**，可以逐行定义并复用。

## 示例程序

### Hello World（标准 BF）

```brainfuck
++++++++[>++++[>++>+++>+++>+<<<<-]>+>+>->>+[<]<-]>>.>---.+++++++..+++.>>.<-.<.+++.------.--------.>>+.>++.
```

### 快速输出 'A'（ASCII 65）

```brainfuck
9[>+++++++<-]>++.   ; 9×7=63，再加 2 得 65，输出 'A'
```

### 使用函数

```brainfuck
'double({)         ; 定义 double 为左移一位（乘 2）
5 double !          ; 输出 10
```

### 栈操作

```brainfuck
5:>3;!             ; 5 压栈，右移，写入 3，弹栈回来，输出 5
```

## 实现细节

- **单元格大小**：8 位无符号整数（`u8`），溢出自动回绕
- **内存模型**：向右动态扩容的 `Vec<u8>`，向左到索引 0 停止
- **栈**：独立的 `Vec<u8>`，与内存带分离
- **函数表**：`HashMap<String, Vec<Token>>`，运行时动态查找
- **解析器**：递归下降，生成树形 AST
- **EOF 行为**：输入结束时 `,` 指令向当前格写入 0
