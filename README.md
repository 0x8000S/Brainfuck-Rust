# BRF — Brainfuck Rust

> 一个基于 Brainfuck 扩展的图灵完备编程语言解释器，使用 Rust 编写。

BRF 在实现 Brainfuck 核心指令集的同时，引入了**数字字面量、函数系统、模块导入、栈操作、行内注释**等现代语言特性，让"只写不读"的 Brainfuck 变得真正可用。

这是作者学习 Rust 过程中的实战项目，从纯 Brainfuck 解释器逐步迭代扩展而来。

---

## ✨ 特性

- **Brainfuck 兼容**：完整支持经典 8 指令
- **数字字面量**：直接写入数值，告别 `++++++++++`
- **可配置循环终止条件**：`[5...]` 可在指定值终止
- **函数系统**：定义和调用可复用代码块
- **模块导入**：将代码拆分到多个 `.brf` 文件
- **行内注释**：`#` 可在任意位置开始注释
- **栈操作**：支持压栈/弹栈，方便临时存储
- **REPL 交互模式**：即时编写和测试代码，状态持久保留
- **自动内存扩展**：无需预设磁带长度

## 📋 指令集

### 核心指令（Brainfuck 兼容）

| 指令 | 说明 |
|------|------|
| `<` | 指针左移一格 |
| `>` | 指针右移一格 |
| `+` | 当前格值 +1（自动回绕） |
| `-` | 当前格值 -1（自动回绕） |
| `.` | 将当前格值作为 **字符** 输出 |
| `,` | 从标准输入读取一个字符到当前格 |
| `[` | 循环开始 |
| `]` | 循环结束 |

### 扩展指令

| 指令 | 说明 |
|------|------|
| `=` | 将当前格清零（设为 0） |
| `~` | 对当前格值按位取反 |
| `{` | 当前格值算术左移 1 位（等价于 ×2） |
| `}` | 当前格值算术右移 1 位（等价于 ÷2） |
| `!` | 将当前格值作为 **数字** 输出（带换行） |
| `:` | 将当前格值压入栈 |
| `;` | 从栈弹出值到当前格（栈空则得 0） |

### 注释

`#` 可在任意位置开始注释，从 `#` 到行尾的内容都会被忽略。空行也会被自动过滤。

```brf
# 这是整行注释
++++++++[>++++<-]  # 这也是注释，从 # 开始到行尾

# 空行不影响执行
```

### 数字字面量

连续的数字字符会被解析为一个数字，自动对 256 取模后写入当前格：

```brf
67.      # 输出字符 'C'
```

### 循环终止条件

BRF 的循环 `[` 支持**可配置的终止条件**：

- 如果循环体**第一个 Token 是数字**，则当当前格值**等于该数字**时终止
- 否则，默认行为与传统 Brainfuck 一致：当前格值为 0 时终止

```brf
# 当当前格等于 5 时停止
[5>+<]

# 传统行为：当前格为 0 时停止
[>+<]
```

### 函数系统

使用反引号 `` ` `` 定义函数，函数名后跟括号包裹函数体：

```brf
# 定义函数 add：将当前格 +1
`add(+)

# 调用函数
add.
```

函数名由连续的非特殊字符组成。函数定义后可在任意位置调用。如需连续调用函数请用`|`分割

### 模块导入

使用 `@文件名|` 语法导入外部 `.brf` 文件并执行：

```brf
@lib.brf|
```

导入的文件同样支持注释和空行，会在当前环境中执行，因此可以复用其中定义的函数。

## 🚀 快速开始

### 构建

```bash
git clone https://github.com/0x8000S/Brainfuck-Rust.git
cd Brainfuck-Rust
cargo build --release
```

### 运行

```bash
# 执行 BRF 文件
cargo run -- file.brf

# REPL 交互模式
cargo run
```

### REPL 模式

REPL 模式下，解释器会**保留运行状态**（内存、指针位置、栈、函数表），方便逐行调试：

```
>>>`add(+)
>>>65add.
B
>>>add.
C
>>>exit
```

```brf
# 定义 add 函数：当前格 +1
`add(+)
```

### 栈操作示例

```brf
# 将 'A' 和 'B' 压栈，然后依次弹出输出
65:           # 将 65 ('A') 压栈
66:           # 将 66 ('B') 压栈
;             # 弹出 66 到当前格
.             # 输出 'B'
;             # 弹出 65 到当前格
.             # 输出 'A'
```

### 循环与终止条件

```brf
# 从 0 数到 9（使用数字终止条件）
`inc(+)      # 定义自增函数
`prt(!)      # 定义数字输出函数（带换行）

[10inc prt]  # 当前格为 0，循环直到等于 10
# 输出 1 到 10，每行一个数字
```

### 位运算

```brf
# 演示按位取反和移位
5!            # 输出 5
~!            # 按位取反后输出（5 的二进制 00000101，取反 11111010 = 250）
{!            # 左移一位（×2），输出 10
}!            # 右移一位（÷2），输出 5
```

### 清零与重置

```brf

```

### 综合示例：简易计算器

```brf

`add(+)      # 加法
`mul({)      # 乘法（左移 = ×2）
```

### 核心组件

- **`EnvVec`**：运行环境，包含数据磁带、指针位置、栈和函数表
- **`Token`**：词法单元枚举，涵盖所有指令类型
- **`CommandContent`**：自定义字符迭代器，支持 `peek()` 和 `to_string()`
- **`parse()`**：递归下降解析器，返回 `(Vec<Token>, usize)` 精确同步索引
- **`read_code_from_file()`**：文件读取器，支持行内注释过滤和空白处理
- **`Token::exec()`**：指令执行引擎

## 🔧 实现细节

### 解析器设计

BRF 采用**递归下降解析**策略。遇到嵌套结构（`[...]`、`` `func(...) ``）时，递归调用 `parse` 处理子内容。

关键设计：**`parse` 返回 `(Vec<Token>, usize)`**，其中 `usize` 表示递归过程中实际消耗的字符数。外层解析器通过 `command_iter.index += consumed` 精确同步游标，避免了"根据 Token 反推字符长度"带来的索引漂移问题。

### 内存模型

数据磁带使用 `Vec<u8>` 动态存储。当指针右移超出当前长度时，`EnvVec::check()` 自动扩容并填充 0。所有运算均使用 `wrapping_add` / `wrapping_sub`，保证 u8 回绕行为。

### 文件加载

`read_code_from_file` 在加载文件时会：
1. 跳过空行
2. 去除每行首尾空白
3. 从 `#` 处截断，丢弃行内注释
4. 将处理后的内容拼接为单行字符串

这使得 BRF 源代码可以像普通编程语言一样分行书写并添加注释，大幅提高可读性。
