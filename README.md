# Brf

用 Rust 编写的 Brainfuck 解释器，支持标准语法与扩展指令。

## 功能

- 完整支持 8 条标准 Brainfuck 指令（`><+-.,[]`）
- 递归下降解析，支持任意深度的 `[]` 嵌套
- 内存带向右自动扩容，向左边界保护
- `u8` 字节回绕（255 + 1 = 0）
- 支持文件执行与交互式 REPL 两种模式
- REPL 模式下内存带状态保持，便于分步调试
- 扩展指令：数字字面量、清零、位运算、数值输出
- 纯标准库实现，零外部依赖

## 安装

```bash
https://github.com/0x8000S/Brainfuck-Rust.git
cd Brainfuck
cargo build --release
```

编译完成后，可执行文件位于 `target/release/brf`。

## 使用

### 文件模式

```bash
brf hello.bf
```

### REPL 模式

```bash
rbf
>>> ++++++++[>++++[>++>+++>+++>+<<<<-]>+>+>->>+[<]<-]>>.>---.+++++++..+++.>>.<-.<.+++.------.--------.>>+.>++.
Hello World!
>>> exit
```

REPL 模式下，内存带状态在多次输入之间保持。

## 扩展指令

| 指令 | 说明 | 示例 |
|------|------|------|
| `0` ~ `9` | 向当前格写入对应数字 | `9` 等价于 `+++++++++` |
| `=` | 将当前格清零 | `=` 等价于 `[-]` |
| `~` | 按位取反 | `~`（0 → 255） |
| `{` | 左移一位（`value *= 2`） | `1{{{` = 8 |
| `}` | 右移一位（`value /= 2`） | `8}` = 4 |
| `!` | 输出当前格的数值（而非 ASCII 字符） | `!` 输出 `65` |

## 实现细节

- 单元格大小：8 位无符号整数（`u8`），溢出自动回绕
- 内存模型：向右动态扩容的 `Vec<u8>`，向左到索引 0 停止
- EOF 行为：输入结束时 `,` 指令向当前格写入 0
- 解析器：递归下降，生成树形 AST（`LEFTW(Vec<Token>)`）
